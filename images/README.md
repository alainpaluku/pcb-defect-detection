# Images d'exemple · Example images

FR : Les six JPEG présents sont des exemples pour une inspection manuelle, et non un jeu de validation indépendant. Les résultats nécessitent des poids PCB entraînés. Le navigateur et l'application de bureau prennent en charge les images usuelles ; la CLI parcourt les extensions JPEG, PNG, BMP, TIFF et WebP sans distinction de casse, récursivement pour les dossiers.

EN: The six included JPEGs are manual inspection examples, not an independent validation set. Inference requires trained PCB weights. Directory inspection recursively finds JPEG, PNG, BMP, TIFF and WebP files, case-insensitively.

Source du dataset mentionnée par le projet / Dataset referenced by the project: [PCB Defects, Akhatova, Kaggle](https://www.kaggle.com/datasets/akhatova/pcb-defects). Vérifiez les droits avant redistribution / Check redistribution rights.
